# XPBottle — плагин "опыт в бутылке"

## Что делает

- `/px [количество уровней]` — берёт пустую стеклянную бутылку в главной руке и
  переливает в неё указанное количество уровней опыта (без аргумента — 1 уровень).
  Требования:
  - в руке должна быть именно `Пустая стеклянная бутылка` (`GLASS_BOTTLE`);
  - у игрока должен быть хотя бы 1 уровень опыта;
  - нельзя указать больше уровней, чем есть у игрока — команда откажет с ошибкой.
- Полученный предмет выглядит как обычная "Бутылка с опытом", но хранит в NBT
  точное количество очков опыта, которое было забрано у игрока.
- Когда игрок бросает такую бутылку и она разбивается, выдаётся **ровно столько**
  опыта, сколько было в неё запечатано (а не случайные 3–11, как у ванильной бутылки).
- Обычные ванильные бутылки опыта (например, купленные у жителей) работают как раньше.

## Сборка

Нужен установленный Java 17+ и Maven, а также интернет-соединение
(Maven скачает Paper API — сам плагин не подключается к интернету во время игры).

```bash
cd xpbottle-plugin
mvn clean package
```

После сборки готовый файл будет здесь:

```
target/XPBottle.jar
```

## Важно про версию сервера

В `pom.xml` указана версия API `1.21.11-R0.1-SNAPSHOT` — под ядро **PaperMC 1.21.11**.
Если позже обновите сервер на другую версию, посмотрите в консоли Exaroton, какая
версия Paper стоит, замените версию в `pom.xml` на соответствующую (например
`1.21.4-R0.1-SNAPSHOT`) и пересоберите плагин командой `mvn clean package`.

Плагин использует только стандартный Bukkit/Paper API, поэтому должен работать
без изменений кода на большинстве версий 1.14+ — обычно достаточно поменять
версию зависимости.

## Установка на Exaroton

1. Соберите `XPBottle.jar` (см. выше) — **важно**: Exaroton не умеет собирать
   Java-проекты сам, jar-файл нужно скомпилировать заранее (локально или онлайн,
   например через Replit или GitHub Actions).
2. Зайдите на панель Exaroton → вкладка **Files**.
3. Откройте папку **plugins** и загрузите туда `target/XPBottle.jar`
   (перетащите файл в окно или нажмите Upload).
4. Убедитесь, что в настройках сервера выбрано ядро **Paper** (не Vanilla/Forge),
   версия — **1.21.11**.
5. Перезапустите сервер через панель Exaroton.

## Использование

1. Наберите в игре хотя бы 1 уровень опыта.
2. Возьмите в руку пустую стеклянную бутылку.
3. Введите команду `/px 5` (перенесёт 5 уровней) или просто `/px` (перенесёт 1 уровень).
4. В инвентаре появится "Бутылка опыта (N XP)" — бросьте её, чтобы вернуть опыт.
